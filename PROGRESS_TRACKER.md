## 🗓️ Overview of Weeks 02 to 08 Problem Topics

### Week 02: Two Pointers, Sliding Window & Sorting (35 Problems)
- Two Pointers (3Sum, 4Sum, Container With Most Water, Trapping Rain Water)
- Fixed Sliding Window (Sliding Subarray Beauty, Max Sum Subarray)
- Variable Sliding Window (Longest Substring Without Repeating Characters, Minimum Window Substring, Permutation in String)
- Cyclic Sort (Missing Number, Find All Duplicates, Set Mismatch)
- Sorting Algorithms & Invariants (Merge Sort, Quick Sort, Dutch National Flag / Sort Colors)

### Week 03: Binary Search & Bit Manipulation (35 Problems)
- Classical Binary Search & Upper/Lower Bound
- Rotated Sorted Arrays (Search in Rotated Sorted Array I & II, Find Minimum)
- Binary Search on Answer / Monotonic Predicates (Koko Eating Bananas, Capacity To Ship Packages, Split Array Largest Sum)
- 2D Matrix Binary Search (Search a 2D Matrix I & II, Median in Row-wise Sorted Matrix)
- Bit Manipulation (Single Number I/II/III, Counting Bits, Number of 1 Bits, Reverse Bits, Subsets via Bitmask)

### Week 04: Recursion, Backtracking & Linked Lists (35 Problems)
- Recursion Foundations & State Trees
- Backtracking Masterclass (Subsets I & II, Permutations I & II, Combination Sum I/II/III, Palindrome Partitioning, N-Queens, Sudoku Solver)
- Singly & Doubly Linked Lists (Reverse Linked List I & II, Palindrome Linked List)
- Fast & Slow Pointers (Linked List Cycle I & II, Middle of the Linked List, Reorder List)
- Advanced Lists (Merge K Sorted Lists, Copy List with Random Pointer, LRU Cache)

### Week 05: Stacks, Queues & Monotonic Data Structures (35 Problems)
- Stack & Queue Fundamentals (Valid Parentheses, Min Stack, Implement Queue using Stacks)
- Arithmetic & Evaluation (Evaluate Reverse Polish Notation, Basic Calculator I & II)
- Monotonic Stack (Next Greater Element I & II, Daily Temperatures, Online Stock Span, Largest Rectangle in Histogram, Maximal Rectangle)
- Monotonic Deque (Sliding Window Maximum, Constrained Subsequence Sum)

### Week 06: Binary Trees, BST & Priority Queues (40 Problems)
- Tree Traversals (Inorder, Preorder, Postorder, Level-Order, Zigzag, Vertical Order)
- Tree Metrics & Structure (Max Depth, Diameter, Balanced Tree, Same Tree, Invert Tree, Symmetric Tree, Subtree of Another Tree)
- Path & Ancestry (Lowest Common Ancestor, Path Sum I/II/III, Binary Tree Maximum Path Sum, Serialize & Deserialize)
- Binary Search Trees (Validate BST, Kth Smallest Element, Lowest Common Ancestor in BST, Insert/Delete in BST)
- Heaps / Priority Queues (Kth Largest Element, Top K Frequent Words, Find Median from Data Stream, Merge K Sorted Lists)

### Week 07: Greedy Algorithms & Graph Theory (40 Problems)
- Greedy Strategy (Jump Game I & II, Gas Station, Task Scheduler, Non-overlapping Intervals, Merge Intervals)
- Graph Representation & Traversals (BFS, DFS, Number of Islands, Max Area of Island, Clone Graph, Rotting Oranges)
- Topological Sort & Cycle Detection (Course Schedule I & II, Alien Dictionary)
- Shortest Paths & MST (Dijkstra's Algorithm, Network Delay Time, Cheap Flights Within K Stops, Prim's & Kruskal's with DSU)
- Disjoint Set Union (Number of Provinces, Redundant Connection, Accounts Merge)

### Week 08: Dynamic Programming & Comprehensive Interview Mastery (45 Problems)
- 1D Dynamic Programming (Climbing Stairs, House Robber I & II, Coin Change, Word Break, Longest Increasing Subsequence)
- 2D / Grid Dynamic Programming (Unique Paths I & II, Minimum Path Sum, Triangle)
- Knapsack Patterns (0/1 Knapsack, Partition Equal Subset Sum, Target Sum, Unbounded Knapsack, Coin Change II)
- String DP & Subsequences (Longest Common Subsequence, Edit Distance, Distinct Subsequences, Interleaving String)
- Palindromic & Interval DP (Longest Palindromic Substring/Subsequence, Burst Balloons)
- Hard Problem Drill & Systematized Review (Mock Interview Sets)
